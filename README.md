# Wordtile 단어 퀴즈

엑셀 단어장이나 문장 파일을 넣으면 듀오링고·퀴즐렛 스타일 퀴즈를 만들어 주는 모바일(세로 화면) 웹앱입니다.
서버 없이 `index.html` 하나로 동작하고, 단어장과 학습 기록은 브라우저(localStorage)에 저장됩니다.

## 문제 유형

| 유형 | 설명 |
| --- | --- |
| 짝 맞추기 | 왼쪽 영어와 오른쪽 뜻을 차례로 탭해서 연결 (타이머) |
| 뜻 고르기 | 영어 → 뜻, 뜻 → 영어 4지선다 |
| 문장 만들기 | 뜻을 보고 영어 단어 타일을 순서대로 탭 / 영어를 보고 우리말 타일 배열 / 듣고 배열 |
| 철자 쓰기 | 알파벳 타일 조합, 직접 타이핑 (오타 1글자는 정답 처리) |
| 플래시카드 | 탭해서 뒤집기, 좌우로 밀어서 알아요/다시 |
| 오답 복습 | 틀린 적 있는 항목만 다시 |

"레슨 시작"은 위 유형을 섞고, 틀린 문제는 레슨 끝에 다시 나옵니다. 영어 발음은 브라우저 음성(TTS)을 씁니다.

## 엑셀 파일 형식

| 영어 | 뜻 |
| --- | --- |
| abandon | 버리다, 포기하다 |
| give up | 포기하다 |
| Practice makes perfect. | 연습이 완벽을 만든다. |

- A열 영어, B열 뜻. 첫 줄 제목은 있어도 없어도 됩니다 (`영어/뜻`, `단어/의미`, `word/meaning`, `문장/해석` 등 인식).
- 번호 열은 자동으로 건너뛰고, 한글이 들어 있는 열을 뜻으로 찾습니다.
- `look/watch`처럼 `/`로 나눈 답은 하나만(또는 순서 바꿔 여러 개) 써도 정답, `take care of + 명사`처럼 `+` 뒤 문법 표시는 채점에서 뺍니다.
- 직접 입력할 때 띄어쓰기는 무시하고, `brother and sister`처럼 and/or로 이어진 말은 순서를 바꿔 입력하거나 타일을 배치해도 정답입니다.
- 네 단어 이상이거나 마침표로 끝나면 문장으로 분류되어 문장 만들기 문제에 쓰입니다.
- `예문`, `예문해석` 열을 추가하면 예문도 문장 문제가 됩니다.
- 시트가 여러 개면 시트마다 단어장을 만들지, 하나로 합칠지 고를 수 있습니다.
- `.xlsx`, `.xls`, `.ods`, `.csv`(UTF-8·EUC-KR), `.txt`를 읽습니다. 텍스트를 직접 붙여넣어도 됩니다.

예시 파일: [`samples/sample-vocab.xlsx`](samples/sample-vocab.xlsx)

## 실행 / 배포

- 로컬: 폴더에서 `npx http-server .` 후 휴대폰으로 접속하거나, PC 브라우저 개발자도구의 모바일 화면으로 확인.
- GitHub Pages: 저장소 Settings → Pages → Source를 이 브랜치(또는 병합 후 `main`)의 `/ (root)`로 지정.

엑셀 파싱은 [SheetJS](https://sheetjs.com) 0.18.5를 `vendor/`에 포함해 오프라인에서도 동작합니다.
